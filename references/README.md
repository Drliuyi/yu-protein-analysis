# Publication reference files

This repository tracks only `SOURCE_MANIFEST.csv`, which records the official
publication URLs, local filenames, roles and expected SHA256 values used by the
reproduction audit.

Downloaded article figures, supplementary PDFs/XLSX files and the pinned
CMAverse source archive are intentionally excluded from GitHub. Obtain the
publication materials from the open-access article package listed in
`SOURCE_MANIFEST.csv`, place them under `references/raw/`, and verify their
SHA256 values before running source-audit stages.

Participant-level UK Biobank data are never distributed with this repository.
